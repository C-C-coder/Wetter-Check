Bergtouren Wetter Ampel
App hilft beim Planen von Bergtouren durch Wetter Check für Orte/Koordinaten und bei Eingabe von Höhenmeter auch Gipfelwetter.
Stündlich aufgelistet.
Warnt vor Weitergefahren am Berg.
Zeigt Sonnen Auf- und Untergangszeiten an.
Verlinkt bei wunsch auf Lawinenwarndienst und Regenradar
